# Photo Frame Maker

A static photo-frame website suitable for GitHub Pages. Image selection and processing happen in the user's browser; no server or API is required.

## Files
- `index.html`
- `style.css`
- `script.js`

## Publish with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload these three files (and this README) to the repository root. Do not upload only the ZIP.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the published website link to appear. Open it and press `Ctrl + Shift + R`.

## Features
- Upload image files (JPG, PNG, WEBP)
- Four simple frame styles
- Zoom and move controls
- Portrait, square and story layouts
- PNG export

The frames are drawn in JavaScript; this is a starter version and does not include external frame artwork.
